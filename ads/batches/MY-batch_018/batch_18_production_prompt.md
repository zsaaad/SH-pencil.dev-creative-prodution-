## Binding rules (every frame)

- **Imagery tier — UPMARKET only.** Modern, well-fitted cafés/restaurants/boutiques, good lighting, clean fit-out; merchant looks successful. NEVER roadside mamak / basic kopitiam / hawker / cluttered / run-down / "cash tin" aesthetics.
- **Faces:** Pan-Asian / Southeast Asian only. Never Western. Diverse & authentically Malaysian (incl. hijab) is good.
- **Never** the word "till"; no old-world cash-register language framing the shop as manual/cash-only — EXCEPT CON-03, where obsolete props (paper spike / cash drawer / ledger) appear *only inside a museum vitrine* as the deliberate joke.
- **No competitors / no third-party logos / app UI** in any frame. Generic fictional signage only.
- Documentary, authentic, cinematic — but aspirational.
- 9:16 → 1080×1920 · 1:1 → 1080×1080. Keep baked hook text inside Meta safe zones (9:16: y 280–1400; 1:1: 64px margins).
- CTA pill: orange `#ff9419`, `BOOK A FREE DEMO`; small StoreHub wordmark. Anchor: From RM3.40/day · 24-hour setup · 20,000+ SE Asia merchants.
