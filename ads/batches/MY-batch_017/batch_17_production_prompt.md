## Binding rules (every frame)

- **Imagery tier — UPMARKET only.** Modern, well-fitted cafés/boutiques, good lighting, clean fit-out; merchant looks successful. NEVER roadside mamak / basic kopitiam / hawker / cluttered / run-down / "cash tin" aesthetics.
- **Faces:** Pan-Asian / Southeast Asian only. Never Western.
- **Never** the word "till"; no old-world cash-register language/props framing the shop as manual/cash-only.
- **No competitors / no third-party logos / app UI** in any frame (no Grab/FoodPanda/Shopee/etc.).
- Documentary, authentic, cinematic — but aspirational.
- 9:16 → 1080×1920 · 1:1 → 1080×1080. Keep any on-image hook text inside Meta safe zones (9:16: y 280–1400; 1:1: 64px margins).
