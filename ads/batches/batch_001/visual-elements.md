## Shared Visual System

All ads in this batch use consistent design tokens:

| Token | Value |
|-------|-------|
| Brand orange | #ff9419 |
| Brand dark | #2f2922 |
| Off-white | #faf7f2 |
| Paper | #f5f5f0 |
| Near-black | #0d0d0d / #0a0a0a |
| Deep dark | #1a1208 |
| Loss/alert red | #e53e3e |
| Warm yellow callout | #fff8e1 |
| Headline font | Barlow Black (900) |
| Body font | Open Sans |
| Divider | 80×4px rect, #ff9419 |
| CTA padding | 20px uniform |
| Frame padding | 32–64px |
| Hardware photo corner radius | 16px |

**Background image treatment:** All non-photo ads use a blurred Unsplash image at 5–12% opacity as a subtle texture layer. Pure photographic ads (T2a, T3a, T7a/b/c) use the photo as full-bleed fill with a gradient overlay.

**Logo placement:** Bottom-right of footer row in all ads. Dark bg → white reverse logo. Light bg → orange logo. Orange bg (#ff9419) → white reverse logo.

**CTA button:** Pill shape (rounded 999) in most fast-ads frames. Rounded rect (8px) in legacy pen file ads. Always "BOOK A FREE DEMO NOW".
