# Ad Inspiration

Auto-populated by the `competitor-ad-inspiration-scan` scheduled task.

A new dated markdown report lands here every other day at 6:00 PM SGT. Each report contains:

- Summaries of currently-running ads from tracked competitors
- Screenshots and direct links from Meta Ad Library, TikTok Creative Center, Google Ads / Display, and curated galleries
- Pattern analysis (hooks, formats, value props, visual styles)
- Actionable takeaways and creative briefs to feed into Pencil.dev ad creation

**Global / Cloud POS expanding into SEA:** Square, Shopify POS, Lightspeed (incl. Vend, Kounta), Toast, Clover, TouchBistro, Revel Systems, Epos Now, Erply, Hike POS, SumUp POS, Zettle, Talech.

## Files

Reports are named `YYYY-MM-DD-ad-inspiration.md`. The most recent is the source of truth for the next ad creation cycle.
