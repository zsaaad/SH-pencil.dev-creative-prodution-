# Adfolio.design → Pencil.dev Prompts for StoreHub

**Source:** PDF scrape of adfolio.design feed (2026-05-29). 150 distinct ads cataloged.
**Purpose:** One Pencil.dev prompt per ad. Each prompt re-themes the original Adfolio pattern for StoreHub (MY EN, F&B + retail SMB, Pan-Asian, no commission/Beep framing).

---

## §0 — HOW TO USE

**Step 1 (paste once per Pencil session) →** Drop §1 GLOBAL BRIEF into the Pencil.dev project brief. This sets brand, language, exclusions for the whole session.

**Step 2 (per design) →** Pick any numbered entry below, paste the **Pencil Prompt** block. Each is fully self-contained — Pencil should produce a 1080×1080 by default. To get the 1080×1920 / 1920×1080 variants ask Pencil to "redesign for vertical reel" or "redesign for landscape feed" using the same prompt.

**Step 3 (export naming) →**
`S1_EN_PostB3_[NN]_[shortname]_[format].png`
e.g. `S1_EN_PostB3_001_closing-sideways_1x1.png`

## §1 — GLOBAL BRIEF (paste once in Pencil)

You are designing static ads for **StoreHub**, an all-in-one POS platform serving 20,000+ F&B + retail merchants across Southeast Asia. This batch is **Malaysia, English-language only**.

**Product anchor:** From RM3.40/day (= From RM3,960/year). 24-hour setup. No training. 17,000+ MY merchants.

**Brand colours (use only these hex codes):**
- StoreHub Orange `#ff9419` — primary, CTA, accents
- StoreHub Black `#2f2922` — text, dark bg
- Bold Orange `#ff630f`, Pink `#ff546f`, Azure `#2a6ee8` — accent only
- Cream `#fff8ea` — typography-led bgs
- White `#ffffff`

**Typography:** Headline = Barlow Black. Sub = Open Sans Semibold. Body = Open Sans Regular. CTA = Open Sans Bold ALL CAPS.

**CTA verbatim, every frame:** `BOOK A FREE DEMO NOW` on an orange `#ff9419` pill button, white text.

**Logo:** StoreHub brand PNG, bottom corner. White wordmark on dark/orange bg, full-colour wordmark on light bg.

**Hard exclusions (do not produce ANY creative violating these):**
- ❌ No delivery commission framing (no "GrabFood takes 30%", no "0% commission")
- ❌ No Beep (QR-ordering product — out of scope this batch)
- ❌ No Western faces, no stock-photo expressions
- ❌ No real competitor brand names (no GrabFood/FoodPanda/Square/Loyverse)
- ❌ No real third-party logos (LHDN, WhatsApp, Google, Grab, etc.) — use stylized stand-ins
- ❌ No unverified claims (no uptime, no security certs, no fake testimonials)

**Imagery:** Pan-Asian merchants only. F&B + retail SMB context (kopitiam, mamak, hawker, cafe, salon, retail counter). Documentary feel, not stock-photo styled. Apply 40–60 blur on photo backgrounds where text overlays; 70–90% opacity colour panel behind text on busy areas.

**Vibe:** Bold, modern, practical, authentic. Restraint over decoration. Headline must be the biggest element on canvas, always.

**Default format:** 1080×1080. Ask me to redesign for 9:16 or 16:9 as needed.

## §4 — WHAT TO TELL PENCIL WHEN IT GETS THE PROMPT WRONG

If Pencil produces a generic Western-looking output:
- *"Re-render with Pan-Asian merchant (Chinese/Malay/Indian Malaysian) in a kopitiam interior. No Western faces. No stock-photo smiles."*

If Pencil uses wrong colors:
- *"Use only `#ff9419` orange and `#2f2922` black plus the specified accent. Re-render."*

If Pencil shrinks the headline:
- *"The headline must be the LARGEST element on canvas. Re-render with the headline at minimum 90pt and occupying at least 40% of the visual weight."*

If Pencil adds a Beep or commission reference:
- *"Remove. This is POS only. Do not mention commission savings, delivery platforms, or Beep QR ordering."*

If Pencil's artifact (#032, #033, #036, #040, #041) doesn't look believable:
- *"The artifact must look 95% native at 2-second glance. Tighten the chrome — fonts, spacing, timestamps, UI colors. The reveal only happens at the bottom-strip CTA."*
